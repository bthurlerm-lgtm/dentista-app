# Dentista App

MVP comercial para clínicas odontológicas.

## Objetivo
Aumentar eficiência operacional e receita da clínica com uma experiência simples para pacientes e equipe.

## MVP atual
- Tela de boas-vindas
- Dashboard mobile
- Serviços e pacotes
- Manutenção ortodôntica
- Limpeza e prevenção
- Loja de produtos
- Página de detalhe de produto/serviço
- CTAs de contratação em modo demonstração
- Design responsivo mobile-first

## Uso
Abra `index.html` no navegador ou publique o repositório como site estático.

## Próxima fase comercial
1. Configurar canal real de contato/pagamento da clínica.
2. Personalizar nome, logo, serviços e preços para o primeiro cliente.
3. Conectar agenda e persistência de dados.
4. Instrumentar funil comercial e conversões.

## Regra do produto
Maior economia. Melhor resultado. Aparência premium.
